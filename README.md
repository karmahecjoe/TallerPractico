# Taller Colaborativo de GIT/GITHUB

## Descripcion del Proyecto
Este proyecto consiste en una pagina personal con tarjetas (cards) de presentacion, donde cada integrante del equipo ha creado su propia pagina con informacion personal y un tema de interes. El proyecto aplica control de versiones con Git y GitHub para el trabajo colaborativo.

## Comandos Git Utilizados
| Comando | Descripcion |
|---------|-------------|
| `git init` | Inicializar repositorio local |
| `git clone` | Clonar repositorio remoto |
| `git add` | Agregar archivos al area de preparacion |
| `git commit -m` | Confirmar cambios con mensaje |
| `git branch` | Crear y gestionar ramas |
| `git checkout` | Cambiar entre ramas |
| `git merge` | Fusionar ramas |
| `git push` | Subir cambios a GitHub |
| `git pull` | Traer cambios de GitHub |
| `git diff` | Comparar cambios entre versiones |
| `git status` | Ver estado del repositorio |
| `git log` | Ver historial de commits |
